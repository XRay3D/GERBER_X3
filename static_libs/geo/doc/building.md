# Сборка

Заголовок: [`CMakeLists.txt`](../CMakeLists.txt).

## Зависимости

Geo — статическая библиотека на **точной** геометрии (CGAL, булевы операции
над дуговыми полигонами). Плавающих геометрических движков в ней нет
вовсе.

* **CGAL** — сначала пробуется `find_package(CGAL QUIET)`; если конфига нет,
  проверяется, видны ли заголовки CGAL компилятору напрямую (CGAL — часто
  header-only), и в этом случае линкуются только `gmp`/`mpfr`. Если не
  видны ни так, ни так — сборка падает с понятным сообщением и командой
  установки под текущую систему (MSYS2/UCRT64, Debian/Ubuntu, ALT/Fedora,
  macOS).
* **Qt6::Gui** (не `Widgets`) — из Qt в Geo только `QPointF`/`QRectF` и
  `QPainterPath`.
* **Threads**, **simdjson** — для параллельного объединения регионов и
  [сериализации](serialization.md).
* **`stdc++exp`** (только GNU) — обработчик нарушений контрактов
  (`pre()`/`post()`) живёт там; без него не слинкуется ничего, что тянет
  заголовки Geo, поэтому линковка `PUBLIC`, а не `PRIVATE`.

## Наружу торчат только заголовки `include/geo/`

CGAL подключается в `CMakeLists.txt` этой библиотеки и целиком остаётся
внутри — в публичных заголовках его нет вовсе, точное состояние спрятано
за PIMPL (`std::indirect`, см. [Polygon и Polygons](polygon-and-polygons.md)).
`src/cgal.h` и `src/offsetcapsules.h` тянут за собой EPECK и доступны
только внутри самой библиотеки (`PRIVATE` include-путь).

## Специфичные флаги CGAL

* **`CGAL_NDEBUG`** — у CGAL свой переключатель assert/precondition,
  независимый от общего `NDEBUG` (и потому не гасится обычным Release). Без
  него после **каждого** join/difference в объединении регионов CGAL
  прогоняет полную проверку всего разбиения плоскости точечной
  локализацией — на дереве слияний (`joinAll`) это умножается на число
  узлов: файл с полутысячей дуговых фигур превращается из «доли секунды» в
  «десятки секунд на каждое join». Входные контуры уже провалидированы
  своими средствами (`isExactContour`, сверка площади с bulge-видом), эта
  проверка CGAL — избыточный дубль поверх готового результата.
* **`CGAL_HAS_THREADS`** — объединение регионов идёт в несколько потоков
  (`joinAll`); без этого определения CGAL считает себя однопоточным и
  правит счётчики ссылок точных чисел без атомарности — гонка на ровном
  месте. Boost обычно определяет его сам, но полагаться на это здесь
  нельзя.
* **`-frounding-math`** (GNU/Clang) — интервальная арифметика CGAL требует
  честного режима округления FPU; флаг стоит только на этой цели, точные
  вычисления целиком внутри неё и остались.
* **`CGAL_NO_GDB_AUTOLOAD`** (только при линкере `mold`) — CGAL 6.2
  вставляет в объектный файл секцию автозагрузки gdb-печатальщиков без
  завершающего нуля; GNU ld и lld это терпят, mold — нет. Убрать флаг, когда
  CGAL починит секцию.

## Тесты

```
option(GEO_BUILD_TESTS "Собирать тесты библиотеки Geo" OFF)
```

Тесты (`tests/test_*.cpp`) — рядом с самой библиотекой: проверяют её же
публичный API, а не приложение поверх него. Включаются
`-DGEO_BUILD_TESTS=ON`. Каждый тестовый файл сгруппирован по модулю
документации:

| Файл | Соответствует странице |
|---|---|
| `test_polygon.cpp` | [Polygon и Polygons](polygon-and-polygons.md) |
| `test_polyline.cpp` | [Polyline и Polylines](polyline.md) |
| `test_inflate.cpp` | [Раздутие и сжатие](offsetting.md) |
| `test_clipopen.cpp` | [Резка открытых путей](clip-open.md) |
| `test_normalize.cpp` | [Нормализация](normalize.md) |
| `test_fill.cpp` | [Заполнение (zigzagFill)](fill.md) |
| `test_cancel.cpp` | [Отмена долгих вычислений](cancellation.md) |
| `test_util.cpp` | [Vertex и bulge](vertex-and-bulge.md), [Трансформации](transform.md) |

Общая сборка всего проекта следует правилам тулчейна из
`~/.claude/CLAUDE.md` (GCC 16 из `/opt/gcc-16`, `-j16`, build-каталоги в
`~/build/`) — Geo как отдельная библиотека этим правилам не противоречит.
