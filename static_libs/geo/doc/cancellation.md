# Отмена долгих вычислений

Заголовок: [`include/geo/cancel.h`](../include/geo/cancel.h).

```cpp
class Cancelled : public std::exception {
public:
    const char* what() const noexcept override;
};

class CancelScope {
public:
    explicit CancelScope(std::stop_token token) noexcept;
    ~CancelScope();
};

std::stop_token cancelToken() noexcept;
bool cancelRequested() noexcept;
void checkCancelled(); // бросает Cancelled, если отмена запрошена
```

## Почему отмена областная, а не параметр функции

Отмена здесь **областная**, а не параметр каждой функции: она объявляется
объектом `CancelScope` на время его жизни и действует на все операции Geo в
этом потоке. Так сделано потому, что параметром её не протащить —
композитные операции региона (`region |= other`) лишнего аргумента не
принимают вовсе, а протаскивание токена через каждую перегрузку
[`Inflate`](offsetting.md) и [`BooleanOp`](boolean-ops.md) раздуло бы API
вчетверо ради того, что почти всегда пусто.

```cpp
void longRunningTask(std::stop_token token) {
    Geo::CancelScope scope{token};
    const Polygons result = Geo::Inflate(hugeRegion, +delta); // отменяемо
} // деструктор возвращает область, действовавшую раньше
```

Области вкладываются: деструктор `CancelScope` возвращает ту область
отмены, что действовала раньше него.

## Почему исключение, а не пустой результат

Прерванная операция **бросает** `Cancelled`. Возврат «пустого» результата не
годится: пустой регион — законный ответ сам по себе (см. эрозию, которая
толще фигуры — [Раздутие и сжатие](offsetting.md#дуга-под-офсетом)), и
вызывающий не отличил бы прерванное вычисление от честно посчитанной
пустоты, а промежуточные стадии конвейера молча считали бы дальше по
мусору.

## Где именно проверяется

Отмена **кооперативна** и срабатывает на границах единиц работы:

* между контурами в `parallelFor`,
* между кусками дерева слияний в `joinAll` (сборка `Polygons` из многих
  полигонов — см. [конструктор `span<Polygon>`](polygon-and-polygons.md#три-конструктора--три-источника-вложенности)),
* между полилиниями в [`ArcRecovery`](arc-recovery.md).

Одиночный точный свип CGAL внутрь себя заглянуть не даёт, так что отклик на
отмену ограничен самой долгой такой единицей — на практике это слияние двух
крупных кусков региона.

## Свой рабочий поток

Стоп-токен — обычный `std::stop_token` из C++20. Рабочие потоки самой Geo
область наследуют (`parallelFor` и `joinAll` ставят её себе сами), а вот
сторонний поток — нет: у него свой `thread_local`, и токен туда нужно
занести таким же `CancelScope`.

```cpp
std::jthread worker([token = Geo::cancelToken()] {
    Geo::CancelScope scope{token}; // токен родителя -- в свой поток
    // ... операции Geo здесь тоже отменяемы ...
});
```
